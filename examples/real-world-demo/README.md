# TW-Enigma & Scramble Real-World Demo

This demo project showcases the full capabilities of TW-Enigma CSS optimization combined with Scramble privacy protection in a realistic web application scenario.

## 🚀 What This Demo Includes

### 1. **Next.js E-commerce Site** (`/nextjs-shop`)
- Product catalog with complex CSS layouts
- Shopping cart functionality
- User authentication forms
- Responsive design with Tailwind utilities
- **TW-Enigma**: Optimizes bundle size and obfuscates class names
- **Scramble**: Protects sensitive user data and form fields

### 2. **React Dashboard** (`/react-dashboard`)
- Data visualization components
- Admin panel with user management
- Real-time analytics charts
- Complex grid layouts
- **TW-Enigma**: Reduces CSS payload for better performance
- **Scramble**: Secures sensitive analytics data

### 3. **Vue.js Portfolio** (`/vue-portfolio`)
- Creative portfolio website
- Interactive animations
- Contact forms
- Gallery components
- **TW-Enigma**: Optimizes animation-heavy CSS
- **Scramble**: Protects contact information

## 🛠 Quick Start

```bash
# Install dependencies
pnpm install

# Run all examples in development
pnpm run dev:all

# Build optimized versions
pnpm run build:all

# Run performance analysis
pnpm run analyze
```
