# Task ID: 2
# Title: Implement configuration template system
# Status: pending
# Dependencies: 1
# Priority: high
# Description: Create a configuration template system that allows the CLI to inject build-time configuration into the scramble script.
# Details:
Create a configuration template in src/index.ts that will be replaced at build time:

```typescript
// Configuration injected at build time by CLI
const CONFIG = {
  SCRAMBLE_INTERVAL: {{SCRAMBLE_INTERVAL}}, // Default: 150
  SCRAMBLE_MODE: "{{SCRAMBLE_MODE}}", // Default: "all"
  CHARSET: "{{CHARSET}}", // Default: "abcdefghijklmnopqrstuvwxyz0123456789"
  DEBUG_MODE: {{DEBUG_MODE}}, // Default: false
  RETRY_ATTEMPTS: {{RETRY_ATTEMPTS}}, // Default: 3
  CLEANUP_INTERVAL: {{CLEANUP_INTERVAL}}, // Default: 30
  MAX_REGISTRY_SIZE: {{MAX_REGISTRY_SIZE}}, // Default: 1000
  PERFORMANCE_MONITORING: {{PERFORMANCE_MONITORING}} // Default: false
};
```

Implement a debug logging utility that only logs when DEBUG_MODE is true:

```typescript
function debug(...args: any[]) {
  if (CONFIG.DEBUG_MODE) {
    console.log('[tw-enigma/scramble]', ...args);
  }
}
```

Create a template processing function in the CLI that will replace these placeholders with actual values based on CLI flags.

# Test Strategy:
Test by manually replacing template variables with test values and verifying the script compiles correctly. Verify debug logging works when DEBUG_MODE is true and doesn't log when false.
