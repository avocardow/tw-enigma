# Task ID: 1
# Title: Set up private package structure
# Status: pending
# Dependencies: None
# Priority: high
# Description: Create the initial package structure for @tw-enigma/scramble as a private package within the monorepo.
# Details:
Create the following directory structure in packages-private/scramble:
- src/index.ts (main source file)
- tsup.config.ts (build configuration)
- package.json (package configuration)

Package.json should include:
```json
{
  "name": "@tw-enigma/scramble",
  "version": "0.1.0",
  "private": true,
  "main": "dist/scramble.min.js",
  "scripts": {
    "build": "tsup",
    "dev": "tsup --watch"
  },
  "devDependencies": {
    "tsup": "^7.1.0",
    "typescript": "^5.1.6"
  }
}
```

tsup.config.ts should configure for IIFE output:
```typescript
import { defineConfig } from 'tsup';

export default defineConfig({
  entry: ['src/index.ts'],
  format: ['iife'],
  minify: true,
  clean: true,
  outExtension: () => ({ js: '.min.js' }),
  noExternal: ['*']
});
```

Create a basic README.md with development setup instructions.

# Test Strategy:
Verify the package structure is correctly set up by running `pnpm build` from the monorepo root and confirming that the scramble package builds successfully. Check that the dist/scramble.min.js file is generated with the expected IIFE format.
