Implement a function to scan all accessible stylesheets and identify tw-enigma generated class selectors using the regex pattern `^\.[a-z][a-z0-9]*$`.

```typescript
interface CSSRuleInfo {
  rule: CSSStyleRule;
  originalSelector: string;
  className: string; // without the dot
}

function discoverTwEnigmaSelectors(): CSSRuleInfo[] {
  const results: CSSRuleInfo[] = [];
  const twEnigmaPattern = /^\.[a-z][a-z0-9]*$/;
  
  try {
    // Iterate through all document stylesheets
    for (let i = 0; i < document.styleSheets.length; i++) {
      const stylesheet = document.styleSheets[i];
      
      // Skip cross-origin stylesheets that can't be accessed
      try {
        // This will throw if stylesheet is cross-origin
        const rules = stylesheet.cssRules || stylesheet.rules;
        
        // Process each rule in the stylesheet
        for (let j = 0; j < rules.length; j++) {
          const rule = rules[j];
          
          // Only process style rules (CSSStyleRule)
          if (rule instanceof CSSStyleRule) {
            const match = rule.selectorText.match(twEnigmaPattern);
            if (match) {
              results.push({
                rule: rule,
                originalSelector: rule.selectorText,
                className: match[0].substring(1) // Remove the dot prefix
              });
            }
          }
        }
      } catch (e) {
        debug('Could not access stylesheet', i, e);
        // Continue with next stylesheet
      }
    }
  } catch (e) {
    debug('Error discovering selectors', e);
  }
  
  return results;
}
```

Implement retry logic to handle cases where stylesheets might not be fully loaded:

```typescript
async function discoverWithRetry(maxRetries = CONFIG.RETRY_ATTEMPTS): Promise<CSSRuleInfo[]> {
  let results = discoverTwEnigmaSelectors();
  let attempts = 0;
  
  while (results.length === 0 && attempts < maxRetries) {
    debug(`No selectors found, retrying (${attempts + 1}/${maxRetries})...`);
    await new Promise(resolve => setTimeout(resolve, 100));
    results = discoverTwEnigmaSelectors();
    attempts++;
  }
  
  return results;
}
```

The regex pattern `^\.[a-z][a-z0-9]*$` is THE CRITICAL pattern that MUST be used for tw-enigma class detection. This pattern specifically matches class selectors that start with a lowercase letter followed by any combination of lowercase letters and numbers, which is the exact format that tw-enigma generates. This pattern is mandatory and non-negotiable for proper scramble effect functionality. Any deviation from this pattern will result in incorrect selector identification and compromise the core functionality of the system.
