# Overview
The Enigma Custom Length Feature allows users to set a minimum length for generated CSS class names using a `--length` global command-line flag. Currently, Tailwind Enigma generates class names based on the optimal length required to accommodate the number of detected class patterns (e.g., 26 patterns = 1 character names). This feature adds explicit control over name length for enhanced security, obfuscation, and consistency requirements.

The primary problem this solves is enabling users to generate longer class names than mathematically necessary, providing enhanced security through obfuscation while maintaining the core optimization benefits of Tailwind Enigma.

# Core Features
1. **--length Global CLI Flag**: Command-line flag accepting values 1-26 that sets minimum class name length
   - Works as a global flag alongside existing `--pretty` global flag
   - Applies to all CLI commands (init-config, css-config, future commands)
   - Overrides automatic length calculation
   - Maintains backward compatibility when flag is not used

2. **Enhanced Name Generation Algorithm**: Updated core name generation to respect minimum length constraints
   - Padding/extension logic for names shorter than minimum length
   - Random character generation for padding when needed
   - Maintains CSS validity and collision avoidance

3. **Global Flag Integration**: Seamless integration with existing global flag architecture
   - Works with existing `--pretty` global flag
   - Consistent flag processing across all commands
   - Global configuration passed to core name generation system

4. **Configuration Integration**: Support for length settings in configuration files
   - Global CLI flags override config file settings
   - Environment variable support
   - Validation and error handling for invalid values

# User Experience
**Primary User Personas:**
- Security-conscious developers needing obfuscation
- Teams with consistency requirements for class naming
- Enterprise developers with strict naming conventions

**Key User Flows:**
1. Basic Usage: `enigma --length=5 css-config` sets all class names to minimum 5 characters
2. Combined Usage: `enigma --pretty --length=3 css-config --strategy chunked` creates aesthetic 3+ character names
3. With Init: `enigma --length=4 init-config` initializes with consistent 4+ character naming
4. Configuration: Set `minimumLength: 4` in config file for project-wide consistency

**UI/UX Considerations:**
- Clear error messages for invalid length values (must be 1-26)
- Warnings for extremely high length values (15+) about performance and file size
- Progress indicators for potentially slower generation with high lengths
- Documentation with capacity tables and performance implications
- Consistent behavior across all CLI commands

# Technical Architecture
**Core System Components:**
1. **Global CLI Flag Processing** (packages/cli/src/index.ts)
   - Add `--length` to existing global options alongside `--pretty`
   - Validate length values (1-26) at CLI entry point
   - Pass validated length to all commands through options object
   - Error handling for invalid values with helpful messages

2. **NameGenerationOptionsSchema Enhancement** (packages/core/src/processors/nameGeneration.ts)
   - Add `minimumLength` field: `z.number().min(1).max(26).default(1)`
   - Update type definitions and validation

3. **Length Enforcement Engine**
   - `enforceMinimumLength()`: Core function to pad/extend names to minimum length
   - `generateRandomPadding()`: Generate random alphabetic characters for padding
   - `validateLengthRequirements()`: Ensure generated names meet length constraints

4. **Enhanced Base Conversion Functions**
   - Update `toCustomBase()`, `toBase26()`, `toBase36()` to accept minimum length
   - Implement padding logic that maintains CSS validity
   - Preserve collision avoidance while enforcing length

5. **Command Integration** (packages/cli/src/commands/)
   - Update all commands to accept global length option
   - Pass length configuration to core name generation system
   - Maintain existing command functionality

**Data Models:**
- Enhanced `NameGenerationOptions` interface with `minimumLength` property
- Updated `EnigmaConfigSchema` to include minimumLength in main config
- Global CLI options interface updated with `length?: number`
- Updated validation schemas and error types

**APIs and Integrations:**
- Backward compatible API - existing code continues to work
- Global flag processing architecture matches existing `--pretty` implementation
- Configuration system integration for persistent settings
- Core package receives length through enhanced options

**Infrastructure Requirements:**
- No additional infrastructure needed
- Existing build and test systems accommodate changes
- Documentation updates for new global flag
