# CSS Logic Processing Requirements - Task 4.1

## Overview
Define the core requirements for parsing, interpreting, and generating CSS from dynamic patterns for the TW-Enigma CSS generation system.

## Input Pattern Requirements

### Pattern Input Formats
1. **Consolidated Pattern Results** - From CompleteConsolidator
   - Map of pattern -> identifier mappings
   - Pattern frequency data
   - Source file locations
   - Validation status

2. **Pattern Analysis Input** - From pattern analysis
   - Array of pattern extraction results
   - Class co-occurrence data
   - Pattern grouping information

3. **CLI Option Integration**
   - Support for --pretty formatting
   - Support for --partial and --readable modes
   - Integration with --max-passes iterations

### Supported CSS Features

#### Core Tailwind CSS Support
- **Utility Classes**: All standard Tailwind utility classes
- **Responsive Variants**: sm:, md:, lg:, xl:, 2xl: prefixes
- **State Variants**: hover:, focus:, active:, disabled:, etc.
- **Dark Mode**: dark: prefix support
- **Arbitrary Values**: text-[14px], bg-[#1da1f2], etc.

#### Advanced CSS Features
- **Logical Properties**: margin-inline-start, padding-block-end
- **CSS Grid**: grid-template-areas, grid-template-columns
- **Flexbox**: flex-grow, flex-shrink, align-items
- **Container Queries**: @container support (future)
- **CSS Layers**: @layer support for modular organization

#### Shorthand Property Handling
- **Margin/Padding**: m-4 -> margin: 1rem
- **Border**: border-2 -> border-width: 2px
- **Font**: text-lg -> font-size: 1.125rem
- **Color**: bg-blue-500 -> background-color: rgb(59 130 246)

## CSS Generation Logic

### @apply Directive Creation
1. **Pattern Consolidation**
   ```css
   .a { @apply flex items-center justify-between; }
   .b { @apply text-lg font-semibold text-gray-900; }
   .c { @apply px-4 py-2 bg-blue-500 text-white rounded; }
   ```

2. **Pattern Validation**
   - Verify all classes in pattern are valid Tailwind classes
   - Check for conflicting property declarations
   - Ensure @apply compatibility

3. **Identifier Generation Integration**
   - Use generated identifiers from CompleteConsolidator
   - Support different identifier strategies (short, readable, semantic)
   - Maintain identifier uniqueness across patterns

### Output Structure Requirements

#### File Organization
1. **Single File Mode** (`--strategy=single`)
   ```css
   /* Generated by TW-Enigma */
   .a { @apply flex items-center; }
   .b { @apply text-lg font-bold; }
   ```

2. **Chunked Mode** (`--strategy=chunked`)
   ```
   dist/css/
   ├── main.css (critical patterns)
   ├── chunks/
   │   ├── components.css
   │   └── utilities.css
   └── manifest.json
   ```

3. **Modular Mode** (`--strategy=modular`)
   ```
   dist/css/
   ├── base.css
   ├── components/
   │   ├── buttons.css
   │   └── cards.css
   └── utilities/
       ├── layout.css
       └── typography.css
   ```

#### CSS Formatting Options
1. **Compact Mode** (default)
   ```css
   .a{@apply flex items-center}.b{@apply text-lg}
   ```

2. **Pretty Mode** (`--pretty`)
   ```css
   /* Pattern: flex items-center (used 15x) */
   .a {
     @apply flex items-center;
   }

   /* Pattern: text-lg font-semibold (used 8x) */
   .b {
     @apply text-lg font-semibold;
   }
   ```

3. **Readable Mode** (`--readable`)
   ```css
   /* Layout utility for flex centering */
   .flex-center {
     @apply flex items-center justify-center;
   }

   /* Typography style for large headings */
   .heading-large {
     @apply text-lg font-semibold text-gray-900;
   }
   ```

## Error Handling Requirements

### Input Validation
1. **Pattern Validation**
   - Invalid Tailwind class detection
   - Circular @apply reference prevention
   - Empty pattern handling

2. **Configuration Validation**
   - Required option presence checks
   - Type validation for all options
   - Range validation for numeric options

### Error Messages
1. **Descriptive Error Reporting**
   ```

   Source: components/Button.tsx:15
   Suggestion: Did you mean 'items-start'?
   ```

2. **Warning System**
   ```
   Warning: Pattern 'flex flex-col' contains conflicting flex directions
   Location: Multiple files (see report for details)
   Recommendation: Review pattern usage for consistency
   ```

## Integration Points

### CompleteConsolidator Integration
1. **Pattern Data Flow**
   ```typescript
   interface PatternData {
     patterns: Map<string, ExtractionResult>;
     statistics: ConsolidationStatistics;
     warnings: string[];

   }
   ```

2. **Identifier Mapping**
   ```typescript
   interface IdentifierMapping {
     original: string;        // "flex items-center justify-between"
   ```
